# Related projects and prior art

GestureForge is independently implemented, while learning from the architecture and behavior of existing open-source projects:

- InputActions: flexible trigger, condition, and action concepts across Linux environments. GPL-3.0.
- linux-3-finger-drag: fail-open evdev multitouch proxy and synthetic touchpad approach. MIT.
- libinput: device normalization, gestures, and hardware quirks.

No source code from those projects is included in the 0.1 foundation archive.
